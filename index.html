    WhatsApp Llamar
    ¿De verdad la web de prueba no tiene compromiso?

    Sí. Le preparamos la web de prueba y usted decide. Si le gusta, llegamos a un acuerdo; si no le convence, nos lo dice y no le volvemos a escribir.

    ¿Cuánto tardan en tener mi web lista?

    Un máximo de 3 días desde que tenemos la información necesaria: textos, fotos y logotipo, si los tiene. Si su web lleva muchos extras, le confirmamos el plazo antes de empezar.

    ¿Qué incluye el precio de 300 €?

    El plan Básico: una web de una página, adaptada al móvil, con sus datos de contacto, botones para llamar o escribir por WhatsApp y un mapa para llegar. Los extras (más páginas, formularios, reservas o idiomas) pueden cambiar el precio; siempre se lo decimos antes.

    ¿Es una suscripción? ¿Hay cuotas mensuales?

    No. Su web se paga una sola vez: no hay suscripción ni cuotas mensuales por el diseño. Lo único que suele tener un coste anual aparte son el dominio y el alojamiento, que dependen del proveedor; se lo explicamos antes de contratar nada.

    ¿Podré cambiar yo mismo los textos o las fotos?

    Depende de cómo se construya su web. Si quiere poder editar usted mismo textos, precios o fotos, coméntelo al principio y le explicamos qué opciones hay y qué implica cada una.

    ¿Ofrecen mantenimiento después de la entrega?

    Si más adelante necesita cambios o ayuda, escríbanos. Le diremos qué se puede hacer y cuánto costaría antes de empezar, sin sorpresas.

    ¿Y el dominio y el alojamiento?

    El dominio (por ejemplo, www.sunegocio.es) y el alojamiento suelen tener un coste anual aparte, que depende del proveedor. Le orientamos para elegir una opción adecuada y le explicamos los costes antes de contratar nada.

    ¿Cuánto cuestan los extras?

    Depende de lo que necesite. Puede hacerse una idea con la calculadora de presupuesto; el precio final se lo confirmamos después de hablar con usted.

    ¿Qué necesito para empezar?

    Solo una llamada o un mensaje. Con el nombre de su negocio, a qué se dedica y algunas fotos (si las tiene) podemos preparar su web de prueba.
